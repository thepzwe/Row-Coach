# Row-Coach
A system that uses your camera to analyze points on your body and track your body position. Gives you tips to help you improve. Its basically a free version of WODProof, Ergatta Coach AI, Asense or even RowerUp. 
Can be run in a browser with ease.
Built by Claude code with some human changes
